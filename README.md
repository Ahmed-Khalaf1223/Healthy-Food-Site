## 🔍 Overview

This website presents a healthy food menu with images, descriptions, and buttons to explore each item. It is built using modern web technologies and is optimized for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structure of the website  
- **CSS3** – Styling and layout  
- **CSS Grid Layout** – For organizing the food items in a grid format  
- **Flexbox** – For responsive design in sections  
- **Media Queries** – To ensure the website looks good on all screen sizes  

## 📱 Features

- Responsive layout for mobile, tablet, and desktop  
- Beautiful food menu with images and details  
- Clean and modern design  
- Easy to customize
